## 实现取舍

CASL已经采用SeqDiff热启动，直接复用，不将其重复包装为新增方法。此前已实现的JAX JIT、常量缓存、减少传输、读取预取、Torch权重转换、compile/CUDA Graph，以及FP16/BF16、25步和DPS稀疏更新继续使用原引擎；不重新写网络，不改变历史实验入口。统一入口为 `python -m cognitive_ultrasound.speedbench`，配置 `configs/speedbench.yaml`。

新增的是保留50步热启动噪声区间、用16/8/4次积分完成修正的候选，复用已有 `preparation.sampling.attach_sampler`。这和原来的native25/10/5不同：后者把热启动起点向后移；新coarse版本仍从initial_step450开始，改变区间内积分步长。两者都改变计算过程，均归为B类，不称为无损、不称为DPM-Solver或SeqDiff+。首帧仍保留500步，不能用稳态速度承诺首帧或短视频总速度。

## 公平比较的实际含义

先按种子锁定2个VAL视频，各取前64帧，不用TEST、不按结果替换病例。每个方法在相同名单和两种协议运行：

1. `fixed`：每帧均揭示相同14条均匀物理列，比较相同观测下的恢复/历史传播。CASL一次更新，BF仍为10＋4两次更新；分组次数是方法成本的一部分，不能称两个恢复器操作数相同。
2. `closed_loop`：CASL按自己的历史和选线继续；BF按自己的10＋4策略继续；插值保持固定均匀观测，不称为主动选线。各自递归的质量和代价才是系统结果。

固定观测不等于固定潜状态，也不等于跨框架相同随机数。JAX保持原生PRNG和相同病例种子；Torch使用显式NumPy噪声。本基准不声称二者逐位可比或通过完整状态等价认证，旧compute_lab的显式共同噪声/梯度诊断继续保留。A类也不会自动被批准用于替换baseline。

质量使用连续[-1,1]极坐标浮点MSE/PSNR、Gaussian SSIM、MAE、未观测区域误差、共同未观测区域误差、时序误差、观测列误差、实际线数，以及与官方输出的掩膜/动作变化。没有uint8量化后再算指标。保留原引擎的输出投影惯例，包括官方非零观测约定；`observed_max_error`会暴露真值恰为零时的差异，不暗中修正历史实现或宣称总是严格一致。本轮不计算EF、分割或任务梯度，速度不能直接外推到这些任务的总训练时间。

## 速度口径

所有方法都在外层围绕完整engine.step计墙钟，包含该引擎实际返回CPU结果、选线和同步；不直接拿JAX和Torch内部定义不同的core_s互比。另记录：加载/构建；首帧；第一个热帧；其后稳态均值、p50/p95；含读取和质量计算的逐帧任务耗时；包含微基准额外工作的病例墙钟。病例墙钟标为case_wall_including_micro_s，包括逐帧JSON、样例和参照NPZ写盘，不包括最后完成标记和整批报告生成；这些写盘不计入逐帧任务时间。

第三帧执行3次预热和20次重复。每次恢复同一输入和历史状态，结束后恢复原状态，不推进正式序列。微基准单列；不能把同一帧重复的最快值当整段帧率。全序列统计去掉首帧与第一个热帧，二者耗时仍显式保留。质量按整个被选片段计算，先帧平均再病例等权，速度也按病例等权；部分完成的组有complete=false，不混称完整比较。

RAM是在每帧结束采样的进程RSS最大值，不含编译子进程、也不宣称系统级连续峰值。显存采用原引擎提供的峰值，分别记录。GPU、UUID、驱动和CPU身份锁入批次；换卡需新输出。代码、权重、数据、配置变化也拒绝混写。

## 运行与产物

本轮不为服务器安装环境。复用已有CASL环境和Torch环境，修改配置里的路径即可。Torch转换资产要求已有 `network.json / ema.npz / probes.npz`，不下载、不训练。BF可保持null，缺口明确记录。

```bash
cd /root/autodl-tmp/cognitive-ultrasound
git pull --ff-only origin main
# 核对 configs/speedbench.yaml 中的数据、两套Python、官方权重和torch_export路径
bash scripts/run_speedbench.sh start
tail -n 40 -F /root/autodl-tmp/outputs_casl/speedbench_v1.console.log
```

`status / stop / resume / report / catalog` 同样由脚本支持。细进度在输出目录的 `<方法名>.console.log`。每个方法独立子进程，默认1800秒超时；超时回收该进程及其子进程，不把失败编译继续挂在后台。运行器复用旧孤儿进程回收与互斥锁。已完成病例经产物SHA检查后跳过；未提交病例重跑。完整完成的方法免重复。unavailable与failed分别登记，任一缺口都会保留finished_with_gaps，不能当作所有方法成功。

输出为配置、catalog、固定名单、资产/代码/硬件身份、环境、日志、逐帧JSON、每病例统计、summary.json/CSV和速度质量图。只为官方参照保留所测片段的输出/掩膜/动作用于比较；每方法每病例只保存首/中/末3帧小样例，不保存每一步DPS粒子轨迹，不复制数据或权重，默认输出上限2GiB。下游研究仍须显式选择加速版本，不能由benchmark自动改变正式模型。

## 验证边界

本地测试覆盖实际HDF5读取、浮点指标、非法掩膜与非有限输出拒绝、同状态微基准恢复、逐病例免重复和产物损坏拒绝、配置变化拒绝，以及真实子进程中失败与成功分开登记。合成引擎仅验证编排，不作为科研测速。实际JAX/Torch CUDA性能、编译/图捕获是否通过、少步后质量如何，均等待服务器运行，不填造测试结果。
