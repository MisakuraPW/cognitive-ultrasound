# 现场讲解提示（不烧录进视频）

这是配合答辩者讲解的 55 秒辅助动画。以下为提示，可按自己的语速简化。

1. **0–12 秒｜扫描成像**  
   探头先发出短脉冲，不同深度的回声先后返回。处理这些回声，就获得一个方向的信息。再逐方向扫描，组成图像并连续更新。开头是传播慢放，后面的扫描和心脏运动换了示意时间尺度。

2. **12–24 秒｜采集取舍**  
   看得更广、更深、采得更密，通常都要花更多采集时间。这里两侧心脏运动来自同一个时钟，左侧等待一帧的时间更长；右侧更早更新，但覆盖或采样信息减少。它是定性总览，没有展示真实帧率。

3. **24–37 秒｜稀疏实测与重建**  
   现在固定范围和深度，只实测少量方向。青蓝线是实测；其余由模型根据观测与学到的图像规律估计，紫色标出估计层。完整外观并不保证所有未采细节正确。

4. **37–55 秒｜下一帧看哪里**  
   橙色表示重建拿不准的位置，不是病灶或真实误差。当前帧重建之后，下一帧把同样数量的线调整到更值得观察的位置。连续看两次换帧：新测量、新重建，再决定后续位置。最后停住，可接着讲自己的研究问题；不要把示意当成自己的实验效果。

可在播放前口头补充“这是合成的原理示意”。如被问及速度：图中不含实际性能数字，收益还取决于重建计算和设备实现。
