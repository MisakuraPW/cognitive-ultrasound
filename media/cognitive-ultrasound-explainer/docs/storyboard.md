# PPT 辅助动画 v2 分镜

总长 55 秒，1650 帧，30 fps。纯白背景，主体为同一个探头、扇形与简化四腔切面。没有独立标题页或结束页，没有烧录旁白。

| 时间 | 画面与动作 | 必要文字 |
|---|---|---|
| 0–5 秒 | 直接出现探头和组织切面。沿一个方向发射短脉冲；150、310、455 个示意距离处分别出现返回波前，先后回到探头。回波返回完成后形成一条灰度线。 | 发射 / 接收；传播慢放示意 |
| 5–12 秒 | 逐方向发射与接收，灰度线累积为完整扇形，随后连续更新心脏图像。与上一动作是不同时间尺度。 | 逐线成像 |
| 12–24 秒 | 原扇形平滑移到左侧，右侧出现较窄、较浅、较疏的同源切面。角度弧、径向尺寸、线条疏密和下方采集时间条同时存在。两侧共享运动时钟；较长采集周期一侧持帧更久。 | 范围；深度；采样密度；一帧采集时间。“看多广、看多深、采多密，都要花时间” |
| 24–37 秒 | 原扇形回到中央统一范围和深度。25.5–28 秒依次获得六个分散方向；30–34 秒紫色估计逐步补充完整图像。实测线始终在上层。 | 实测；重建估计 |
| 37–42 秒 | 当前估计上出现橙色局部热区；六个橙色虚线候选方向显现，其中三个穿过主要热区。时序箭头指向下一帧。 | 重建不确定性；候选方向；当前帧 → 下一帧 |
| 42–48.2 秒 | 进入下一帧，清除上一帧测量，按新位置逐条采满六条，再形成新估计。另一局部出现不确定性；候选线为再下一帧调整。 | 保留实测 / 重建估计及简洁时序标签 |
| 48.2–53 秒 | 第二次换帧，按新的六个方向采集，再完成重建。保留局部热区，既不清零也不声称必然改善。 | 同上，候选方向在换帧后退出 |
| 53–55 秒 | 完整保持“重建图＋六条实测线”及局部不确定性两秒。无淡出、无结尾总结页。 | 必要对象标签 |

颜色之外增加线型区分：实测为青蓝实线＋细浅描边；估计为紫色虚线扇形边界；候选线为橙色虚线；局部热区有橙色点线轮廓。文字深灰，对象标签随其语义使用颜色。说明和来源在 README，不形成常驻页脚。
