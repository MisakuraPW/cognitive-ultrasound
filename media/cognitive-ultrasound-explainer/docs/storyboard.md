# 分镜与节奏
总长 115 秒，1920×1080，30 fps，烧录中文字幕，静音独立可读。持续保留同一个探头、扇形区域和四腔切面示意。先完成科学边界核对，再据下表落实制作。

| 时间 | 主动作 | 解释重点 |
|---|---|---|
| 0–5 秒 | 探头接触胸壁，扇形内简化心腔缓慢搏动 | 引入如何看见心脏；此时是组织结构示意 |
| 5–16 秒 | 局部脉冲波前向深处走；浅、中、深界面各自产生回波，并先后返回；时间标尺逐个记下 | 回波不是只来自最深处；传播明确慢放，回波时间对应深度 |
| 16–22 秒 | 接收信号经过“信号处理”，同方向灰度亮暗扫描线出现 | 扫描线是处理后显示，不是回波构成声束 |
| 22–30 秒 | 扫描方向由探头向外发散，逐条填充 | 帧的采集逐步发生 |
| 30–38 秒 | 同一切面持续运动，三个小扇形形成短时间轴 | 连续图像组成视频 |
| 38–47 秒 | 扇形平滑缩小移向左侧；右侧同范围同深度的稀疏扫描作对照，18 与 6 个示意时间格推进 | 每格为发射与等待回波；数值仅教学设计，非设备参数 |
| 47–57 秒 | 同一心动时间函数，密线侧保持上一帧更久，疏线侧较早更新 | 不改变影片播放速度；线密度不等同真实空间分辨率 |
| 57–62 秒 | 左侧扇形回到主位置，逐渐变窄，角间隔近似不变 | 看见的范围变小，所需方向变少 |
| 62–73 秒 | 扇形回到原宽度；暂时缺测，随后依次采集 6 条分散实线 | 第一帧初始化仅作示意 |
| 73–80 秒 | 独立绘制的模型估计逐步显现，紫色虚线边界与青色实测线并存 | 不把估计当测量，不保证细节正确 |
| 80–92 秒 | 三种可能的合成重建有局部差异，主图叠加橙色柔和热图 | 模型拿不准，不是病灶、诊断概率或已知真实误差 |
| 92–105 秒 | 先显示下一帧候选虚线；在 97 秒、101 秒切换本帧的 6 条实测方向 | 当前重建安排下一帧；不在同帧无限补采；三帧线数不变，热图保留且不单调消失 |
| 105–115 秒 | 回到持续运动的完整重建示意，保留实测线和估计图例 | 工作原理与研究目标，不声称临床优势或设备实时实现 |

全部动画由帧号驱动；固定种子 20260922。实际项目不运行模型、训练或科研实验。没有可用的授权中文语音工具，因此本版不含配音、音效或背景音乐。字幕时间是阅读节奏，不伪称音频对齐。完整旁白见 narration.md。
