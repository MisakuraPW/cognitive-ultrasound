# 中文旁白稿

115 秒，当前成片无音轨。以下文稿与烧录字幕一致，后续配音需对齐标注时间。

- **0—5 秒**：心脏在不停跳动。超声怎样看见它？

- **5—10.5 秒**：探头发出短促的声波，再接收组织返回的回声。

- **10.5—16 秒**：不同深度都有回声。回来得越晚，对应的位置越深。

- **16—22 秒**：经过信号处理，回声的强弱变成这一方向上的亮暗。

- **22—30 秒**：探头依次改变扫描方向，一条条扫描线组成一帧图像。

- **30—38 秒**：连续更新的图像，让我们看见心脏运动。

- **38—44.5 秒**：同样的深度、同样的范围，每条线都需要发射和等待回波。

- **44.5—50.5 秒**：采得密，空间采样更充分，但完成一帧通常需要更久。

- **50.5—57 秒**：采得疏，可以更早更新，但直接测到的信息也更少。

- **57—62 秒**：缩小扫描范围也能加快更新，但看见的范围会变小。

- **62—68 秒**：来不及每个方向都仔细看，能不能先看更有价值的位置？

- **68—73 秒**：先采分散的少量扫描线。实线标出的，是实际测到的信息。

- **73—80 秒**：结合已测信息与模型学到的图像规律，估计完整图像。估计可能有误。

- **80—86 秒**：几种可能的重建，在局部意见不一致。

- **86—92 秒**：橙色表示模型更拿不准，不是病灶，也不是诊断概率。

- **92—98 秒**：这一帧重建之后，把下一帧的扫描方向安排到更值得观察的位置。

- **98—105 秒**：每帧还是同样多的线，改变的是位置。不确定性仍可能存在。

- **105—110 秒**：有限的采集时间，优先观察更值得看的位置。

- **110—115 秒**：认知超声：让采集与重建相互配合。
