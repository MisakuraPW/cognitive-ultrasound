# PyTorch CASL 移植：本地验证记录

日期：2026-09-22。实现和验证针对固定官方 CASL/zea 版本，不涉及学长未提供的代码。

- 真实官方 EMA 的 85 个 Keras 层导出并由原生 PyTorch 执行；不训练、不更新任何权重。
- 本地 CPU，真实权重输入探针：去噪输出最大绝对差 4.2915e-6；DPS 输入梯度最大差 4.1723e-7；熵最大差 1.1921e-7；选线完全一致。
- 测试 9 项通过，1 项 CUDA Graph 回放测试跳过（本机 PyTorch 2.9.0+cpu，无可用 CUDA）。测试覆盖三步完整官方求解器/投影、官方 RNG 拆分与显式噪声重放、aot_eager fullgraph 输入梯度及改变输入、零熵平局语义、禁止 CPU 冒充 CUDA Graph、失败报告不能宣称达到 32 FPS、固定配置边界、拒绝重复 GPU worker 和续跑累计费用保护。
- CPU 的编译检查使用 `aot_eager` 验证捕获及梯度语义；不等于已经验证 Linux GPU Inductor/Triton 性能或 CUDA Graph。云端 compile/graph 作业会重新检查真实帧输出，并保留错误和限时状态。
- Ruff、Bash 启动器语法、无 GPU plan 检查通过。所有源码通过 Git 交付；结果目录不进 Git。
- 尝试只读连接用户原 AutoDL 地址，连接被拒绝；没有得到 GPU 测速，也没有开启实例、停止其它任务或安装 CUDA。

因此目前可以说“权重与主要计算语义的移植验证通过”，还不能说“比官方快多少”或“4090 已达到 32 FPS”。这些数值由服务器实际结果生成；不能把上述 CPU 数值误差当作 GPU 帧率证据。
